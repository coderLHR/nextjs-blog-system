- **路由入口**：`src/app/showcase/page.tsx` 作为 Next.js App Router 页面，负责元数据配置并渲染 `ShowcaseShell`。
- **布局容器**：`ShowcaseShell.tsx` 实现主界面逻辑，包含可折叠的左侧导航侧栏（按功能分组）和右侧内容展示区，支持键盘快捷键切换演示。
- **演示组件库**：`demos/` 目录下存放独立的演示组件（如 `AbilityModel3DDemo`, `SidebarConnectionDemo`），通过 `index.ts` 统一导出。
- **技术实现**：结合 React Hooks 管理状态，使用 Three.js 实现 3D 可视化，利用 SVG 和 DOM 事件处理实现 2D 交互连线。
