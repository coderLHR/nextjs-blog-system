- 自定义 Hook `useDragList` 被广泛用于实现列表项的拖拽排序功能，统一处理 dragStart, dragOver, drop 等事件逻辑。
- 在 `EditPage` 中采用组件隔离模式，将 `AbilityGroupSection`, `UnitRow`, `CourseCard` 等拆分为独立组件，以确保 `useDragList` 在每个列表中仅被调用一次，符合 React Hooks 规则。
- 全局状态管理依赖于组件内部的 `useState` 和 `useEffect`，并通过 `fetch` 与本地 API 路由进行初始数据加载和状态持久化尝试。
- UI 布局大量使用 Tailwind CSS 的固定定位 (`fixed inset-0`) 和高 zIndex 策略，以实现覆盖全局导航的全屏沉浸式体验。
