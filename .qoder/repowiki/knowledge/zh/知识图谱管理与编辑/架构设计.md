- 采用 Next.js App Router 架构，通过 `src/app/knowledge-map/` 下的 `page.tsx` 定义全屏路由入口。
- 核心交互逻辑封装在 `src/components/knowledge-map/` 中，包含 `KnowledgeMapSelector`（选择器）和 `EditPage`（编辑器）两个主要客户端组件。
- 数据层由 `data.ts` 提供，包含静态 Mock 数据生成器及 O(1) 复杂度的层级查找 Map，供前端组件直接消费。
- API 层通过 `src/app/api/knowledge-map/route.ts` 提供简单的 GET/POST 接口，目前使用内存变量存储配置状态，实现前后端数据同步原型。
- `NavController` 组件通过 DOM 操作动态调整全局导航栏样式，实现全屏应用下的悬浮显示效果。
