- **前端架构**：采用 Next.js App Router，`page.tsx` 作为客户端入口协调状态，组合 `ChatSidebar`（会话列表）、`ChatArea`（消息展示）和 `ChatInput`（输入交互）等原子组件。
- **后端接口**：通过 `/api/ai` 下的 Route Handlers 实现 RESTful API，涵盖会话 CRUD (`sessions`)、消息查询 (`messages`)、配置管理 (`config`) 及核心聊天流 (`chat`)。
- **数据与安全**：依赖 Prisma ORM 进行持久化，集成 `getSession` 确保接口鉴权，并在 `config/route.ts` 中使用自定义加密工具保护 API Key。
- **流式通信**：`chat/route.ts` 实现了 Server-Sent Events (SSE) 风格的流式转发，将外部 AI 模型的流式响应实时推送至前端。
